# Duck syrinx multiome analysis

Analysis code for single-nucleus multiome (snRNA-seq + snATAC-seq) and single-cell RNA-seq of the developing duck syrinx.

> Mishkind D, Lee C, Prabhakara C, Tir P, Kingsley EP, Clarke JA, Goller F, Tabin CJ. Epigenetic memory of early left-right patterning and integration of left-right asymmetry with sexual dimorphism in the duck syrinx. *Proc Natl Acad Sci USA* (2026, in press).

**Status:** the code will be released here, with a Zenodo DOI, when the paper is published.

## Data Availability

- **Single-nucleus multiome** (duck HH13–HH25 and the chick control cohort): GEO [GSE336327](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE336327) (BioProject PRJNA1481253)
- **3′ single-cell RNA-seq** (duck E6/E9/E11): GEO [GSE336329](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE336329) (BioProject PRJNA1481424)
