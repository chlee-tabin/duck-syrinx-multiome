## Build / regeneration

Panels render via their own scripts; the compositor `figures/fig03/generate.py` writes `figures/fig03.pdf`:

```
conda run -n duckfig Rscript figures/fig03/panel_A_pitx2c_signal.R   # panel A
conda run -n duckfig Rscript figures/fig03/panel_B_lr_counts.R       # panel B
conda run -n duckfig Rscript figures/fig03/panel_C_pileup.R          # panel C
conda run -n duckfig python3 figures/fig03/generate.py               # -> figures/fig03.pdf
```

`figures/fig03/_focal_window.R` is the shared focal-window helper sourced by the panel scripts. The dorsal RNA control needs `h1_dorsal_pseudobulk.py` on the cluster → `h2_dorsal`; both are wired into `run_pipeline.sh` (h1/h2) and the derived-data manifest.

Upstream tables (cluster-bound unless noted):

```
# f5 region counts (panel A) — cached-input mode while f1 is purged
sbatch pipeline/run_f5_pitx2_from_cache.sh            # not distributed
# f4 per-embryo-half coverage (panel C): the shipped f4 export (split-tube aliquots pooled);
# needs f1, so rebuild f1 from the fragments first (below)
sbatch pipeline/run_f4_perembryo.sh
```

Regenerating the panel A and C inputs from fragments (f1 rebuild, f5, shipped f4, then a
comparison with the committed tables; header of each script gives sizing):

```
bash scripts/repro_fig5/setup_and_stage.sh     # transfer node: clone + stage the v2.1.0 fragments
bash scripts/repro_fig5/submit_chain.sh cache  # login node: f5 --from-cached-matrix
bash scripts/repro_fig5/submit_chain.sh pilot  # login node: f1 import pilots
bash scripts/repro_fig5/submit_chain.sh rest   # login node: f1 imports -> f1 aggregate -> f5 -> f4 shipped -> compare
```

The compare job (`compare_fig5_inputs.py`) exits non-zero unless every check passes, so its
sacct STATE is the verdict; `out/compare/summary.tsv` lists each check.

## Narrative / rationale

Figure organization across the paper:

| Figure | Modality / scope |
|---|---|
| fig01 | Experimental design + preparation |
| fig02 | snRNA-seq spatial subclustering + laterality |
| **fig03** | **snATAC-seq laterality — PITX2 focal locus** |
| fig04 | Cross-species (duck vs chick) — incl. the duck Pitx2-TAD gene-track |

There is no schematic panel in fig03; the PITX2-locus chromatin signal carries the figure directly.

fig02 establishes laterality in the snRNA-seq data, but at HH17/16 the snRNA laterality signal is weak (figS02 panel D): per-genotype L/R calls there are low-confidence. fig03 opens (A) by showing that the PITX2c signal — snRNA PITX2 + its promoter chromatin — is a decisive per-embryo bisection signal, isoform-specifically (only PITX2c, not PITX2a/b), and is what anchors the HH17/16 L/R assignment (the chromatin-arbitrated inference, `d2n`). With those firm sides (B), the snRNA is nearly silent at HH17/16 (2 Right-biased DEG, inference pool) — yet in the same multiome cells the PITX2 ±500 kb chromatin is already L-biased (L peaks ≫ R) and stays L-biased through HH25, in the ventral inference pool but not detectably in the dorsal compartment (0 L / 0 R locus peaks at every stage — read as absence of detection, not demonstrated bilaterality: the dorsal arm is underpowered at the focal promoter, see the panel-C notes; the dorsal snRNA arm is 0 at HH17/16 and small-and-Right at HH21/HH25 — see the panel B block). C shows the coverage shape behind that count: a focal-locus L/R chromatin pileup in which the PITX2c promoter (the load-bearing, CpG-island memory element) is Left-biased accessible signal in the ventral lanes and maintained across HH17/16 → HH21 → HH25, while the PITX2a/b promoters show no consistent L/R bias (isoform-specific within-locus control — the controlled contrast) and the dorsal lanes are underpowered at this promoter (no detected bias). The persistence of the focal chromatin L-bias across the transcriptionally silent gap is the figure's take-home (a primed / memory-bearing chromatin state). The TAD-wide substructure (the upstream-desert late R-drift) lives on the 359-peak gene-track in fig04 (the duck-vs-chick figure). Genome-wide L/R is not biased — at HH17/16 the nominal L- and R-biased peak counts both sit inside the label-shuffle null (7,338 L / 9,690 R vs shuffle medians 8,117 / 8,947, emp P 0.83 / 0.31; `h4` on the tail-correct binomial) — so the chromatin laterality is focal, not global (stated in the text; the genome-wide screen + per-subcluster DEG overlap are figS03).

## Methodology trimmed from the legend

### Panel A
- HH13 / HH21 / HH25 sides come from the snRNA 4-metric inference (`d2l`); the ATAC separation there is cross-modal corroboration. No p is drawn on the panel; the per-stage statistics (paired DESeq2, paired and unpaired Wilcoxon) are in `step_f5_pitx2_region_stats.tsv` and Methods §1.10. At HH17/16 the side comes from the chromatin PITX2c inference itself (`d2n`), so that column is the side-defining signal (no circular p reported).
- Same-side duplicates (lane-loading-record tube group 17-B(2) = embryos 17-5/17-6, not repo embryo 17-B: one left half sequenced in GEX04 and GEX0S-duck = G3_unfiltered_donor0 / donor3) arrive from f5 as ONE half with library `GEX04+GEX0S-duck` (`figures/_shared/lr_firmness.py`). Its snRNA point is the pooled mean of the two libraries' `pitx2_mean`, weighted by their snRNA inference-pool nuclei (`d2l_lr_inference.tsv` `n_inference`); it has no R half, so no paired segment. Every ATAC half must have an snRNA value (missing raises).
- f5 sides are cross-checked against `lr_inference_multiome.tsv` before plotting: a plain-library half must match the sidecar's side and must not be a `same_side_dup` row; a pooled `<libA>+<libB>` half must consist of `same_side_dup` rows on its side. Any disagreement stops the render.
- Statistics on the current table (paired DESeq2, `step_f5_pitx2_region_deseq2.tsv`, R 4.4.0 + DESeq2 1.46.0 locally): PITX2c promoter HH13 7/7 pairs +1.73, padj 4.2e-5; HH17/16 9/9 +1.06, 1.3e-2 (no p shown on the panel at HH17/16 by design); HH21 8/8 +1.56, 4.4e-27; HH25 8/8 +1.46, 1.5e-17; PITX2b HH25 padj 0.21 (n.s.); paired Wilcoxon p 0.035 / 0.014 / 0.014 at HH13 / HH21 / HH25. Panel-A medians (fragments per nucleus, `step_f5_pitx2_region_stats.tsv`, L / R): PITX2c HH13 0.104 / 0.038; HH21 0.143 / 0.048; HH25 0.132 / 0.054; PITX2b HH13 0.135 / 0.100; PITX2a HH21 0.029 / 0.022. ## Methods notes & disclosures

- The PITX2 ATAC L/R signal **characterizes** the FISH/design-established left population — the side inference (`d2l`/`d2n`) is PITX2-based, so panel A is the side-defining signal, **not independent laterality proof**. Independent laterality is the snRNA / FISH / design evidence (fig02) plus the genome-wide concordance (figS03). Panel A is honest about this via the per-stage side-source strip (snRNA-led = cross-modal corroboration; chromatin-led HH17/16 = side-defining).
- Depth/cell normalization is sound (DESeq2 genome-wide poscounts size factors, r(libsize, size_factor) = 0.9987); the matched-power CPM control (figS03) confirms the L-bias survives subsampling to common n → biology, not power.
- The panel C HH13 lane is **descriptive only** (no stars): HH13 ATAC has just 1L/2R firm-side embryo-halves and single-digit fragments at the locus, below the laterality-test floor. The HH13 wave-1 signal is carried by the snRNA (panel B + fig02), not the ATAC pileup.
- Panel C's coverage visual and DESeq2 stars are **both per-embryo-half** (each stage × compartment × genotype × side embryo-half weighted equally) **and both use the d2n chromatin-canonical HH17/16 L/R sides** (the same axis as panel A/E and figS03 — g1 reads `lr_inference_multiome`): the coverage and the star on each lane describe the *same* L/R partition. The pileup averages the per-half accessibility shape; the stars ((b′) paired within-population) test whether the per-embryo-half L-vs-R difference is significant. At HH17/16 the pooled-unpaired `g4f` gives PITX2c +1.55 log2FC, padj_locus 2.1e-4 (disclosed only — no panel star). The ventral-L bias survives equal per-half weighting. Current render (raw, before the per-lane background matching): ventral whole-window L/R 1.99 (HH17/16), 1.42 (HH21), 1.45 (HH25) against peak-free background L/R 1.95, 1.33, 1.38; dorsal 1.28 / 1.04 / 1.08 against 1.11 / 0.89 / 1.07, all three n.s. — underpowered at this promoter, see the Panel C block.
- **Panel B dorsal control — the FAM241A caveat.** FAM241A is R-biased in the dorsal pool at both HH21 (−1.00, padj 2.2e-3) and HH25 (−2.83, padj 1.2e-19) and should be discounted on annotation grounds: the ZJU1.0 FAM241A transcript-isoform model erroneously folds a neighbouring **eRNA locus** into the FAM241A transcript, so its signal tracks the upstream PITX2-TAD gene-desert (the same upstream-R drift carried on the fig04 gene-track), not a focal dorsal laterality gene. It is not the whole dorsal signal: the dorsal arm is 13 genes at HH21 and 16 at HH25 (CDH13, CDH18, GRID2, NEBL, CREB5 … at HH21; CSMD1, PTPN3, LOC106016802 … at HH25), every one of them Right-leaning bar a single HH25 gene. Setting FAM241A aside leaves 12 and 15 — quote the counts.
